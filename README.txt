PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com (create an account if needed).
2. Create a new PUBLIC repository named: alyanabila.github.io
   If that name is unavailable or you prefer another username, use your GitHub username instead.
3. Upload index.html, README.txt, and the entire assets folder to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for deployment and open https://YOUR-GITHUB-USERNAME.github.io/

Official guide: https://docs.github.com/en/pages/quickstart

Note: The final live URL requires publishing from a GitHub account you control. This bundle is ready to upload but is not itself hosted yet.
